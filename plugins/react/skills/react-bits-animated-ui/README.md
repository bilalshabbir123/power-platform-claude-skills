# react-bits-animated-ui

**Problem it solves:** adding React Bits animations to business apps without breaking accessibility, bundle size, the code app CSP, or the React Bits licence.

**Use it when:** adding animated text, backgrounds, micro-interactions or cards to a code app, SPFx web part or React app.

**What's inside:** install commands (shadcn / jsrepo), variant choice, licence rules (MIT + Commons Clause), reduced-motion hook, lazy loading, CSP table, examples, mistakes, checklist.

**Related skills:** `power-apps-code-app-deployment`, `sharepoint-spfx-web-parts`, `power-platform-solution-builder`
