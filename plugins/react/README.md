# react plugin

React UI skills: animated components with React Bits, accessible and CSP-safe for code apps, SPFx and custom React apps.

## Skills
- [`react-bits-animated-ui`](skills/react-bits-animated-ui/)

## Install

```
/plugin marketplace add bilalshabbir123/power-platform-claude-skills
/plugin install react@power-platform-claude-skills
```

## Test

```bash
claude plugin eval plugins/react --runs 1 --no-publish
```
