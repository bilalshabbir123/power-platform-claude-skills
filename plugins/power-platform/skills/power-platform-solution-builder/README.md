# power-platform-solution-builder (hub)

**Problem it solves:** one place to start for any Power Platform / Microsoft 365 build without loading every product's rules at once.

**Use it when:** choosing between canvas app, code app, SPFx or a custom React app; a request spans several products; or you're not sure which skill applies.

**What's inside (`SKILL.md` + `references/`):**
- Technology decision table and shared standards (solutions, env vars, connection references, Dataverse-first, security, testing)
- Licensing, DLP, performance-limit and ALM tables across products
- `references/`: code-apps, canvas-apps, power-automate, sharepoint-spfx, custom-react-apps, react-bits-ui, custom-llm-unsloth — each read only when needed (progressive disclosure)

**Related skills:** all skills in this repo; install the `sharepoint`, `react` and `ai-models` plugins too for the full set.
