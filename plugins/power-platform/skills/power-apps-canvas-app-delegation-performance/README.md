# power-apps-canvas-app-delegation-performance

**Problem it solves:** canvas apps that silently miss records (delegation), start slowly, or fail to save without telling the user.

**Use it when:** you see a delegation warning, a gallery shows too few records, `OnStart` is slow, or you're choosing canvas vs code app.

**What's inside:** canvas vs code app table, delegation rules and the current data row limit (500 default, max 10,000), CountRows vs CountIf, named formulas, Patch error handling, examples, mistakes, checklist.

**Related skills:** `power-platform-solution-builder`, `power-automate-dataverse-triggered-flows`, `power-platform-solution-release-alm`
