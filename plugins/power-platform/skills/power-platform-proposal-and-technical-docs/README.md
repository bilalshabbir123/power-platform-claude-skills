# power-platform-proposal-and-technical-docs

**Problem it solves:** proposals and technical summaries that go out with placeholder prices, numbers that disagree, day totals that don't add up, claims the sold plan can't meet, jargon the client can't follow, or Word formatting faults.

**Use it when:** writing, reviewing or reissuing a proposal / RfP response, writing a short technical build summary ("max 3 pages", "simple words"), or a handover document for a Power Platform, Microsoft 365, SharePoint or Claude-on-Microsoft-365 solution.

**What's inside:** reading order and facts sheet, document types and what each contains, plain-English rules, one summed component table, data-residency and licence checks, .docx generation rules (fonts on every run, ZIP folder entries, Word PDF page count), mistakes, pre-send checklist.

**Related skills:** `pwa-client-requirements-clarification-doc`, `power-platform-solution-builder`, `power-platform-solution-release-alm`
