# sharepoint plugin

SharePoint Framework (SPFx) web parts and extensions: Heft toolchain, data access, permissions, throttling and CI releases.

## Skills
- [`sharepoint-spfx-web-parts`](skills/sharepoint-spfx-web-parts/)

## Install

```
/plugin marketplace add bilalshabbir123/power-platform-claude-skills
/plugin install sharepoint@power-platform-claude-skills
```

## Test

```bash
claude plugin eval plugins/sharepoint --runs 1 --no-publish
```
