# sharepoint-spfx-web-parts

**Problem it solves:** SPFx builds that break on the wrong Node version or toolchain, over-privileged API permissions, throttling failures, and unreproducible `.sppkg` releases.

**Use it when:** creating or upgrading SPFx web parts/extensions, or showing Power Platform data inside SharePoint, Teams or Viva.

**What's inside:** Heft toolchain and Node choice (SPFx 1.24), data-access table (PnPjs, Graph, AadHttpClient, Dataverse), governance, security, performance, CI, examples, mistakes, checklist.

**Related skills:** `power-platform-solution-builder`, `react-bits-animated-ui`
