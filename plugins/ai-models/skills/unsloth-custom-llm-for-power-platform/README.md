# unsloth-custom-llm-for-power-platform

**Problem it solves:** fine-tuning a model on your own data and calling it from Power Platform without data leaks, timeouts, licence problems or ungoverned connectors.

**Use it when:** deciding between built-in AI and fine-tuning, training with Unsloth, or connecting a self-hosted model to a flow or app.

**What's inside:** decision table, architecture, data preparation, Unsloth install/train/export code (from the official notebook), evaluation gate, hosting, custom connector + DLP, 120 s timeout, ALM, licensing, examples, mistakes, checklist.
