# azure-low-cost-poc-hosting

**Problem it solves:** POC hosting that costs money for nothing, is painfully slow in a demo, or stops working mid-month because the free database paused.

**Use it when:** setting up App Service + Azure SQL + Storage for a POC, before and after a demo, or when a free-tier database is paused.

**What's inside:** F1 vs B1, the free Azure SQL offer and its one-way "bill over usage" setting, what wakes the database, managed identity without keys, demo-day commands, budget alert, examples, mistakes, checklist.

**Related skills:** `pwa-offline-first-sync`, `entra-id-msal-pwa-sign-in`
